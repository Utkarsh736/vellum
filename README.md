# Vellum

A lightweight, private, **offline-first** PDF & EPUB reader.

Desktop (Tauri v2 · React · TypeScript · Tailwind) and Android (Kotlin · Jetpack Compose) share one Rust core. Book files stay on disk; the app never uploads, indexes, or copies their contents.

**Zero telemetry. No network permission. No account.**

---

## Features

- **Library** — import PDFs and EPUBs; covers, titles, and authors from file metadata
- **Reading progress** — resume where you left off (PDF page or EPUB CFI), debounced saves
- **Desktop** — sidebar layout, virtualized cover grid, keyboard shortcuts, drag-and-drop
- **Android** — Storage Access Framework (open files in place), Material 3, TalkBack-friendly
- **Privacy by design** — SQLite holds only library fields; covers live in OS cache; no `INTERNET` on Android

## Repository layout

```text
vellum/
├── core-lib/       Shared Rust core (SQLite, metadata, UniFFI)
├── desktop/        Tauri v2 + React frontend
├── android/        Kotlin + Compose app
├── docs/           Privacy, reading engine, accessibility notes
├── scripts/        Binding generation & Android native build
└── generated/      UniFFI Kotlin bindings (regenerated by script)
```

## Quick start

### Prerequisites

| Component | Required for |
|-----------|----------------|
| [Rust](https://rustup.rs/) (1.77+) | Core, desktop, Android native lib |
| Node.js 18+ | Desktop only |
| Android SDK + NDK, [cargo-ndk](https://github.com/bbqsrc/cargo-ndk) | Android only |

### Shared core (tests)

```bash
cd core-lib
cargo test
```

### Desktop

```bash
cd desktop
npm install
npm run tauri dev          # development
npm run tauri build        # production bundle (.dmg / AppImage / etc.)
```

See [desktop/README.md](desktop/README.md) for platform packages and privacy notes.

### Android

```bash
# From repo root — cross-compile the core into jniLibs
cargo install cargo-ndk
rustup target add aarch64-linux-android x86_64-linux-android
./scripts/build-android-core.sh

# Then open android/ in Android Studio, or:
cd android && ./gradlew :app:assembleDebug
```

See [android/README.md](android/README.md) for UniFFI regeneration and SAF details.
